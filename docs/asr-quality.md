# ASR 补漏、对齐检查与缓存

本地识别完成后检查词级时间。默认单词超过 2.5 秒、起止时间相同、时间倒退或缺少时间字段均视为可疑；多词对齐项按词数放宽词长阈值。可疑区间前后各补 3 秒，用原音轨和当前 Whisper 模型独立重识别，关闭 VAD、开启逐词时间，不沿用上一次文本上下文。局部结果替换对应词区间，保留两侧文字。重识别为空或仍有异常时间时，停止该步骤，不保存错误词表。

敏感补漏阶段只去除同一时间位置的相同文本。发生在其他时间的重复讲话保留。补漏结果完整包含原区间文字且有新增内容时，采用补漏结果；有冲突的重叠区间交给局部独立重识别。旧的 `recovery_max_overlap_ratio` 参数仅为兼容保留，不再用于丢弃整段文字。

局部重识别最多尝试三次：原区间、前后各扩大 3 秒、前后各扩大 6 秒。每次仍须通过词级时间检查；采用扩大区间的结果时，同步替换扩大区间的原词，避免重复。三次均失败才停止。每次尝试的文字、词级时间及无效区间写入 `output/log/asr_quality/recovery_*.json`，其中词级时间相对于该识别音频块，`clip_offset` 为全片偏移。

若某次独立重识别仍有异常词级时间，在扩大语境之前，使用已加载的声学对齐模型将该次候选文字重新对齐到原音轨。对齐必须保留全部识别词，且通过同样的时间检查；不能删除异常词来通过检查。诊断保留对齐前的结果及声学对齐是否成功。这样句尾短词的零时长或跨动作停顿的长词不会仅因解码器时间估计不稳定而反复重识别。

独立重识别中的孤立零时长短词允许有限插值：文字长度不超过 8、置信度至少 0.6、前后词均有正时长且与零时长点相接（误差不超过 20 ms），三词总范围在 60–800 ms 内。保留三词总起止时间和文字，只重新分配其内部时间，并记录 `original_timing` 和 `timing_method`。连续零时长词、低置信度、跨静音或长范围不作插值，仍触发重试或失败。这用于处理 “we’re going to” 等连读中的单词时间塌缩，不用于给疑似幻觉文字凭空补时长。

配置：

- `whisper.alignment_repair_enabled: true`：启用局部修复。
- `whisper.max_word_seconds: 2.5`：词长检查阈值。

识别成功后写入 `output/log/asr_manifest.json`，记录源视频 SHA-256、识别配置（不含 API 密钥）、模型目录及识别处理代码摘要。源视频、参数或相关代码变化后，原词表、分句、翻译、字幕及配音缓存归档到 `output/backups/asr-stale-*`，再重新生成；源视频变化或无法确认旧缓存来源时也归档提取音频。原视频、旧备份、运行中的服务日志保留。

没有清单的旧识别结果在下一次运行识别步骤时会归档并重跑一次，包括此前手工修正的中间文件。成功生成新清单后，输入和设置不变则复用缓存。导入的 SRT 或上传者字幕（具有 `source_subtitle_segments.xlsx` 和识别词表）仍按导入字幕流程跳过 WhisperX。

这三项防护不能覆盖所有漏字：没有异常词长、没有补漏冲突的遗漏仍可能未被发现。语音覆盖率检查未包含在本次改动中。

验证：`scripts/test_asr_quality.py` 包含重复讲话、重叠新增文本、冲突重识别、异常词长、区间替换和缓存归档检查。另以本次 02:30–03:05 原音轨回放旧错误词表，实际 large-v3 局部重识别恢复了赞助口播，消除了 16 秒词长；首次识别及对齐输入在这项回放验证中使用旧结果，未重跑整片 WhisperX。
