# 流程控制与追加成品

主页面最上方的「流程控制」统一管理整个任务。上传或下载之前即可配置；a 区只负责视频来源，b 区展示翻译及字幕进度，c 区展示配音状态，成品区保留各个版本。

## 配置任务

- 成品可独立选择「原声字幕视频」「配音视频」，也可同时选择。
- 两项都不选时仍生成翻译稿和字幕文件，不生成视频。
- 原声字幕视频可以选择仅译文或双语；配音视频可以选择仅译文、双语或不显示字幕。
- 「翻译完成后，等待我校对」控制翻译后的人工确认点；「更多人工确认点」中可选择术语确认。
- 「视频准备好后自动开始」只响应新的上传或下载事件。已有视频、修改计划、追加成品及中断后的恢复均需要明确点击开始。
- 所有设置统一点击「应用设置」后才生效，同时记作下一次任务的默认值。未应用时明确提示，当前任务仍使用已应用的设置。
- 顶部单选方案包括字幕直出、校对后配音、双版本全自动及自定义。选中项有单选标记、强调背景、边框和勾号。选择方案只填写下方选项，不保存也不启动处理。
- 下方「查看并自定义」可以保留方案原值，也可以调整。手动调整任一选项后，方案显示为「自定义」。设置预览立即显示成品、人工确认点和启动方式；其下的「当前已应用的流程」仍展示实际执行的已保存计划，避免把草稿误认为已生效。

顶部预览会显示自动步骤、确认点和已完成步骤，运行时显示当前阶段。运行中的处理参数锁定，暂停会在当前操作完成后生效；需要修改剩余任务时，先停止，等待当前操作结束，再应用新设置并继续。停止不会删除已完成结果。

快捷方案和草稿选项在独立的 Streamlit fragment 中刷新，不会每次都重绘侧栏、视频和成品区。「应用设置」会刷新整页以同步实际计划；任务结束时也会同步一次整页以解锁参数。配置 YAML 和语言 JSON 按文件修改时间及大小缓存，文件变更后重新解析；配置写入会立即使缓存失效。

## 校对、错误与恢复

等待校对和任务完成是不同状态。等待校对时可打开文件，保存修改后点击「确认校对并继续」。关闭某个正在等待的确认点后，仍须点击「继续自动处理」确认恢复，不会因为修改设置而突然启动。

错误状态提供「重试失败步骤」，同一运行会从失败步骤继续；程序重启后按现有文件及任务记录重新规划。没有完成的配音任务会保留已生成的片段供后续复用。程序中断时不会自动恢复，以免重复处理。

## 追加配音

原声字幕视频完成后，成品区可以展开「追加配音视频」，选择字幕显示方式，再点击「开始生成配音视频」。追加不会覆盖原声字幕视频，也不会重新执行已完成的识别和翻译。

首次接管没有任务记录的旧输出时，会基于当前文件建立基线；对这些旧文件未记录的生成参数不作追溯推断。此后翻译稿、术语、配音参数及字幕显示方式的变化由任务记录跟踪。

## 版本与复用

- 修改翻译稿后，相关字幕和视频会标记为需要更新；开启校对时需要重新确认。
- 修改术语会使翻译及后续结果需要更新。
- 只修改配音视频的字幕显示方式时，复用已完成的配音音频，只重新合成视频。
- 修改配音引擎或配音参数时，重新生成配音，原声字幕视频不受影响。
- 重新生成之前，旧成品和受影响的缓存移入 `output/versions/`，不直接删除；旧成品在新版完成前仍可查看。
- `output/workflow_state.json` 保存源视频标识、任务选项、确认记录、当前状态和成品版本。不同源视频不会复用同一个任务的结果。

任务不会自动归档；所选成品完成后可在成品区手动归档到 history。

## 验证范围

计划层覆盖确认点、追加配音、翻译和术语修改、仅字幕显示变更、配音变更、错误、中断及旧版本保留。Streamlit 界面测试使用模拟处理步骤走通人工校对、双版本自动处理、追加配音与失败重试。FFmpeg 测试使用合成短片实际生成原声字幕视频和三种字幕模式的配音视频；不会为验证界面而调用付费翻译服务或重跑整片语音识别。
